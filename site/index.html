What it does

Watches your disk

Free space in the menu bar, an alert before you run out, and a dashboard of what is taking the room.

  • Clears only caches that rebuild themselves, automatically if you like
  • Everything else goes to its own trash first, with undo

Nine focused tools

Scan, review, then act on only what you tick.

  • Uninstaller and app leftovers
  • Large, old and duplicate files
  • Developer junk: Xcode, simulators, Docker, Homebrew
  • AI models and caches, login items, Bins

Clipboard history

Press ⌃⌘V anywhere to pick something you copied earlier and paste it.

  • Searchable, with pinned items
  • Never saves what password managers mark as secret

The first time you open it

  1. Unzip the download and drag Reclaim into your Applications folder.
  2. Open it. macOS will say it cannot check the app for malicious software, because Reclaim is not signed with a paid Apple developer certificate. Click Done.
  3. Go to System Settings → Privacy & Security, scroll down, and click Open Anyway next to Reclaim. Confirm with your password. You only do this once.
  4. From the menu bar, choose Start at login. For the clipboard shortcut, turn Reclaim on under Privacy & Security → Accessibility when asked.
Prefer the terminal? After moving it to Applications, this clears the download flag in one go: 
xattr -dr com.apple.quarantine /Applications/Reclaim.app

Privacy

Stays on your Mac

Reclaim has no account, no analytics and no server. The dashboard runs on your own Mac and needs a private token to open. Clipboard history is stored in a file only your user can read.

One optional exception

If you have the claude command-line tool installed, Reclaim can ask it to describe folders its own rules do not recognise. That sends the folder's path to Anthropic. Turn it off under Settings → Ask Claude about unknowns.

Build it yourself

On an Intel Mac, or if you would rather not run a downloaded app, build from source. You need Python 3.10 or later from python.org.

git clone https://github.com/psarmmiey/reclaim.git
cd reclaim
./build-app.sh
